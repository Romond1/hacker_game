# Mission reveal and Home Base visual pass

## Visual thesis

The mission overlay behaves like a friendly arcade command transmission: it arrives with a deliberate pop, types its instructions at a readable pace, and celebrates completion with one large reward reveal. The Home Base keeps its existing section order but makes the next action easier to find.

## Content and interaction

1. Keep the localized mission steps and practice rules. Animate each overlay entrance and exit; type the English instruction progressively, with the complete text available immediately to assistive technology. Never delay the player's Next or X action. Reduced-motion users see all content immediately.
2. Make Access Granted the visual high point: congratulatory heading, unlocked mission reward, server-awarded XP and Credits, count-up from zero, and a single soft completion flash. Keep Final Score quieter, but count its total upward and mark the final number. Reuse existing sound effects only when the player has enabled sound.
3. Retain the Home Base order: identity/rank/stats, Training Center and Shop, current mission, mission grid. Reduce current-mission panel height and title size, shrink radar, improve English-first and support-language labels, emphasize Start Mission and the available mission card, and give unlocked training buttons a lively but restrained invitation to click.
4. Verify keyboard focus, no score/timer during the guide, all three mission completions and graduation routing. Browser-check the layout at 1440px desktop width and the animation states; run unit, build, and server-contract checks.
