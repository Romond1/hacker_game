# Phase 2.2 Mission 4 and Data Transfer Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Mission 4 as a short right-click copy/paste introduction and unlock a reusable five-round Data Transfer Training module with capped Credit rewards and persistent results.

**Architecture:** Extend the existing data-driven `MissionDefinition` with an optional transfer challenge and teach the generic `MissionRunner` how to select, copy, paste, and submit without creating a Mission 4-only screen. Generalize the existing Training session/server validation around a discriminated module kind so Systems Calibration and Data Transfer share lifecycle, scoring, reward, persistence, results, and teacher aggregation.

**Tech Stack:** React 19, TypeScript, Vitest/Testing Library, Vite development API, PHP 8/MariaDB production API, Playwright browser verification.
